Fokus: rekomendasi layanan dan pembuatan IaC

Start aplikasi lokal.
Lalu paste prompt Azure.

App-nya sudah ada. Tidak perlu membuat project baru atau download ZIP. Buka folder yang benar, jalankan aplikasinya, lalu minta rekomendasi di Copilot Chat mode Agent. Ikuti empat langkah ini.

Mulai dari folder app
Panduan utama

Terminal untuk menjalankan app. Chat untuk meminta rekomendasi.

1 / di VS Code

Buka folder app, bukan folder panduan HTML.

Pilih File → Open Folder, lalu pilih folder berikut. Di dalamnya harus terlihat package.json, server.js, dan folder public.

demos\copilot-azure-terraform\app

HTML ini cukup dibuka di browser sebagai panduan. Yang menjadi konteks Copilot adalah folder app di VS Code.

2 / di terminal VS Code

Jalankan aplikasi.

Pilih Terminal → New Terminal. Pastikan lokasi terminal berakhir dengan \app, lalu jalankan:

npm start

Biarkan terminal itu tetap terbuka. Setelah muncul alamat server, buka http://127.0.0.1:3000. Anda akan melihat daftar keluhan dummy.

Kalau alamat itu sudah bisa dibuka, server masih berjalan. Tidak perlu menjalankan npm start dua kali. Server yang dibuka Copilot di background juga bisa tetap berjalan walaupun terminal Anda tidak menampilkannya.
Baru pertama kali atau muncul error dependency belum ada?

Jalankan ini dari folder app, tunggu selesai, lalu ulangi npm start:

npm ci
Muncul EADDRINUSE atau port 3000 sudah dipakai?

Cek dulu apakah portal demo sudah berjalan. Jangan mematikan proses lain. Jika ingin menggunakan port lain, jalankan di terminal baru dan buka alamat dengan port yang sama:

$env:PORT = "3001"
npm start
3 / di Copilot Chat, bukan terminal

Gunakan prompt rekomendasi Azure.

  1. Tetap di VS Code yang membuka folder app.
  2. Buka chat baru. Ketik @azure dan pilih Azure dari daftar, jika tersedia.
  3. Untuk mengikuti sample artikel, salin pertanyaan singkat ini lalu Enter:
@azure what Azure services should I deploy my app to?

Itu cukup untuk meminta rekomendasi. @azure memilih asisten Azure; konteks aplikasinya tetap dari workspace. Prefix @azure saja, tanpa pertanyaan, belum menjelaskan tugasnya.

Jika @azure tidak muncul: gunakan mode Agent dan prompt 2. Setelah rekomendasinya sesuai, baru minta Terraform melalui prompt 3. Prompt panjang itu versi terarah untuk tahap lanjutan, bukan syarat prompt singkat pada artikel.

Prompt 1 tidak wajib. Itu hanya alternatif menjalankan app. Jangan paste npm start ke browser atau prompt chat ke terminal.

Copilot tahu app yang dimaksud dari file dalam workspace. Azure tidak otomatis mencari atau mengunggah aplikasi localhost.

4 / setelah selesai mencoba

Matikan server, bukan hanya tab browser.

Jika Anda menjalankan npm start sendiri: kembali ke terminal yang masih menampilkan log server, klik terminal itu, lalu tekan Ctrl+C. Tunggu sampai prompt terminal kembali. Jika Windows meminta konfirmasi penghentian batch, jawab Y.

Menutup tab browser tidak mematikan server. Setelah server berhenti, alamat lokal tidak bisa diakses lagi. Data JSON dan lampiran tidak dihapus; untuk menyalakan lagi cukup npm start.

Kalau server dijalankan Copilot di background?

Ctrl+C di terminal lain tidak akan mematikannya. Minta di chat yang menjalankan server tersebut. Tombol ini hanya menyalin permintaan, bukan langsung mematikan proses.

Matikan hanya server Portal Keluhan Mini yang kamu jalankan di background
dari folder app demo ini. Jangan hentikan proses lain atau menghapus data.
Jika tidak bisa memastikan proses milik demo ini, jangan menghentikan
proses apa pun; jelaskan dahulu. Konfirmasi setelah server berhenti.

Prompt 3 / setelah Anda review dan setuju

Buat Terraform, berhenti sebelum deployment.

Jalankan di chat rekomendasi yang sama hanya jika rencananya sudah Anda setujui. Pembuatan IaC dan deployment adalah dua tahap berbeda.

Lihat prompt lengkap
Saya menyetujui rencana yang baru kita review, untuk membuat Terraform
lokal saja. Jika rencananya belum ada di chat ini, berhenti dan minta
saya menjalankan prompt rekomendasi terlebih dahulu.

Buat Terraform Azure sesuai rencana di folder infra:
main.tf, variables.tf, outputs.tf, terraform.tfvars.example, dan README.
Gunakan Terraform CLI langsung tanpa azd. Untuk latihan ini, pakai
state lokal, jangan membuat atau menghubungi backend remote.
Jangan mengisi atau mengarang subscription ID, tenant ID, principal ID,
region yang belum dipilih, atau credential; gunakan variabel/placeholder.

Periksa dokumentasi provider/module, gunakan versi kompatibel yang dikunci,
dan jelaskan pilihan konfigurasi. Jangan menyimpan secret atau menampilkan
access key dalam output. Jangan menyebut hasil ini siap produksi.

Jalankan terraform fmt -check, terraform init -backend=false,
dan terraform validate dari infra. Jika fmt gagal, format lalu cek lagi.
Laporkan hasil tiap perintah; jangan menyamakan validate dengan bukti
bahwa permission, biaya, atau resource Azure sudah benar.

Jangan menjalankan terraform plan, apply, import, destroy, azd up,
atau perintah Azure yang membuat/mengubah resource. Jangan deploy app.
Jika butuh login untuk suatu pemeriksaan, berhenti dan jelaskan dahulu.
Terakhir beri link file Terraform dan catat perubahan integrasi app
yang belum dikerjakan.
Yang harus terlihat: file .tf dan laporan fmt/init/validate. Belum ada resource baru, belum ada aplikasi di Azure.

Perintah terminal dan tool mungkin meminta izin. Cek sebelum mengizinkan. Azure login, plan, estimasi biaya, apply, dan deployment app dibahas terpisah setelah scope sandbox disetujui.
